# Arbitrary Precision Calculator

Arbitrary Precision Calculator implemented using Doubly Linked List in C to perform arithmetic operations on very large numbers beyond standard data type limits.

---

## 📌 Overview

This project performs arithmetic operations on large integers that cannot be handled using standard C data types such as `int` or `long long`.

Each digit of the number is stored in a node of a Doubly Linked List, enabling efficient manipulation of extremely large numbers.

---

## 🚀 Features

- Addition of large numbers
- Subtraction of large numbers
- Multiplication of large numbers
- Division using repeated subtraction
- Handles numbers beyond standard integer limits
- Command-line based execution

---

## 🛠 Technologies Used

- C Programming
- Doubly Linked List (DLL)
- Dynamic Memory Allocation
- Command Line Arguments
- Modular Programming
